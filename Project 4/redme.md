## 📌 01. Project Overview

The **Message Intelligence System** is a Machine Learning based classification project designed to identify whether a message is **Spam or Legitimate**.

This project applies different supervised machine learning algorithms, probability concepts, and classification evaluation techniques to analyze message patterns and detect unwanted messages.

The system also provides an interactive Streamlit application where users can enter a message and receive a prediction using a selected trained model.

## 🎯 02. Project Objectives

- Understand message classification using Machine Learning.
- Perform dataset analysis and preprocessing.
- Implement K-Nearest Neighbors (KNN).
- Implement Support Vector Machine (SVM).
- Implement Gaussian Naive Bayes.
- Understand Conditional Probability and Bayes' Theorem.
- Compare classification models using evaluation metrics.
- Develop an interactive Streamlit application.

## 📂 03. Dataset Information

| Property | Details |
|---|---|
| Dataset Name | Message Intelligence Dataset |
| File Format | Excel (.xlsx) |
| Total Records | 5,200 |
| Total Features | 16 |
| Target Column | `spam_label` |
| 0 | Legitimate |
| 1 | Spam |
| Problem Type | Binary Classification |

### Dataset Features

| Feature | Description |
|---|---|
| message_length | Total message characters |
| word_count | Number of words |
| num_urls | Number of URLs |
| num_digits | Number of numeric digits |

| legit_keyword_score | Legitimate keyword count |

| sender_account_age_days | Sender account age |

## 🏢 11. Business Applications

This system can be useful for:

- Email Spam Detection
- SMS Filtering
- Unwanted Message Detection
- Message Security Analysis
- Communication Monitoring

### Business Recommendation

A real-world deployment should select a model based on Precision, Recall, F1 Score, prediction speed, and the cost of incorrect classifications.

High Recall can help detect more spam messages, while high Precision can reduce legitimate messages being incorrectly marked as spam.
